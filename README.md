# KODE — CodeIgniter 4 + React

A responsive digital studio website with a CodeIgniter 4 backend and React/Vite frontend.

## Run locally

1. Copy `env` to `.env` and set `CI_ENVIRONMENT = development`.
2. Install dependencies: `composer install` and `npm install`.
3. Start CI4: `php spark serve`.
4. In another terminal, start Vite: `npm run dev`.

Build production assets with `npm run build`, then serve the project from the `public` directory.
